# نسخة أسواق بدر المحلية لنظام Windows

هذه نسخة Electron لواجهة أسواق بدر، تعمل بقاعدة بيانات محلية محفوظة في ملف بيانات التطبيق على هذا الكمبيوتر. لا تحتاج إلى API أو إنترنت لتسجيل الدخول أو البيع أو إدارة المخزون، ولا تتزامن تلقائيًا مع أجهزة Android؛ لكل جهاز قاعدة بيانات مستقلة. قارئ الباركود USB الذي يحاكي لوحة المفاتيح يكتب في حقل الباركود، وتُستخدم مفاتيح الاختصار الظاهرة في واجهة نقطة البيع.

## الدخول لأول مرة

عند أول تشغيل أنشئ حساب مدير وحدد كلمة مروره. لا توجد كلمة مرور افتراضية. بعد ذلك يُنشئ المدير حسابات الموظفين ويحدد الأدوار ورقم PIN لكل منهم. كلمة مرور المدير المخزنة محليًا تكون مشتقة ومملحة وليست نصًا صريحًا؛ لكن كلمة مرور التطبيق لا تعني تشفيرًا كاملًا لملف البيانات. استخدم حساب Windows مقفلًا وتشفير الجهاز لحماية بيانات المتجر عند فقدان الكمبيوتر.

## البيانات والاستيراد

تبقى المبيعات والموظفون والمخزون والورديات والحضور والمصروفات على هذا الكمبيوتر. لا تدخل بيانات النسخة السحابية القديمة تلقائيًا. استورد ملف XLSX/CSV للأصناف على كل جهاز تريد تشغيله؛ وسيكون ملف كل جهاز مستقلًا. لا يُرسل التطبيق بيانات المتجر إلى الإنترنت.

## البناء والتشغيل

من جذر المشروع ثبّت Node.js وpnpm ثم نفّذ `pnpm install`. لبناء الواجهة استخدم `pnpm desktop:build`، ولتشغيل نسخة التطوير `pnpm desktop:dev`، ولبناء Windows استخدم `pnpm desktop:dist:win`. على Windows أو Linux مع Wine ينتج مُثبّت NSIS؛ وإذا لم يتوفر Wine على Linux ينتج مجلدًا محمولًا `win-unpacked` يحتوي `Aswaq Badr.exe` وملفات التشغيل اللازمة.

قد يعرض Windows SmartScreen تحذيرًا لأن الحزمة غير موقعة رقميًا. مسح الكاميرا مخصص لنسخة Android؛ وعلى Windows استخدم قارئ باركود خارجيًا يعمل كلوحة مفاتيح.
