# أسواق بدر — برنامج إدارة سوبرماركت محلي

تطبيق Android وWindows لإدارة البيع والمخزون والمنتجات والموظفين والورديات والحسابات التشغيلية. تعمل كل نسخة ببيانات محفوظة محليًا على الجهاز، من دون API أو مزامنة أو اتصال إنترنت أثناء التشغيل.

- Android: Expo/React Native، تخزين SQLite محلي، ومسح باركود بالكاميرا؛ إعداد APK يحجب إذن الإنترنت.
- Windows: Electron، تخزين محلي، دعم لوحة المفاتيح وقارئ باركود USB.
- بيانات الدخول: ينشئ المدير كلمة مروره عند الإعداد الأول؛ لا توجد كلمة مرور افتراضية. الموظفون يُدارون محليًا بكود وPIN وأدوار.
- استيراد المنتجات: Excel/CSV بعناوين عربية أو إنجليزية مرادفة.
- Android APK: بعد قبول checkpoint، اختر ملف EAS `preview` في Dashboard؛ هذا الملف مضبوط على توزيع داخلي بصيغة APK.
